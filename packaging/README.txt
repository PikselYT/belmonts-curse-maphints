Map Hints - plugin-only package
================================
Shows the secrets and collectibles you still miss on the in-game map of Castlevania: Belmont's Curse.

1. You need the BepInEx 6 (IL2CPP) mod loader, build 6.0.0-be.789, in the game folder.
   (The Spell Swap installer sets it up: https://github.com/PikselYT/belmonts-curse-spellswap)
2. Extract this zip into the game folder (the one with "Castlevania Belmont's Curse.exe").
   You get BepInEx\plugins\MapHints\MapHints.dll.
3. Get the map data from your own game with the companion tool (version 1.2.0 or newer):
   https://github.com/PikselYT/belmonts-curse-secret-hints  -> setup.bat, then run_extract.bat.
   It copies the data into BepInEx\plugins\MapHints\data by itself.
4. Start the game and open the map. F10 turns the highlights on/off.

Full documentation: https://github.com/PikselYT/belmonts-curse-maphints
